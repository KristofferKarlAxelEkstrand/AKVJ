# Clip Format

The JSON formats — `meta.json`, `clips.json`, `key-map.json` — are the only bridge between
`mainframe` and `akvj`. The two realms share no JavaScript imports, so these files carry the
whole contract.

## Principles

**Human first.** A person opens `meta.json` in a text editor and understands every field. The
baseline workflow for adding a clip is manual: drop a sprite in a folder, write the JSON by hand.

**Machine compatible.** Mainframe reads and writes the exact same format a human writes — no
injected bloat, no stripped formatting. The engine ingests it fast enough for a 60fps loop.

**Golden rule.** If a schema change makes the file harder to write by hand, it is a bad change.

## Where the files live

```
projects/{projectId}/clips/{clipId}/meta.json     hand-authored or written by mainframe
projects/{projectId}/clips/{clipId}/sprite.png    the sprite sheet
projects/{projectId}/clips/clips.json             generated: flat catalog keyed by clipId
projects/{projectId}/key-map.json                 MIDI placement, DAW channels 1–16
```

`clips.json` is generated by `npm run clips` and copied to `akvj/src/public/`. Never hand-edit
the generated copies — the pipeline overwrites them.

## `meta.json` fields

### Sprite sheet

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `png` | string | `sprite.png` | Sprite sheet filename |
| `frames` | number | — | Total frame count. Legacy alias `numberOfFrames` still resolves. |
| `framesPerRow` | number | — | Frames per row in the sheet |
| `frameWidth` | number | `240` | Cell width in pixels |
| `frameHeight` | number | `135` | Cell height in pixels |

`frames` and `framesPerRow` are required — the pipeline rejects a clip without both.

### Rendering

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `scaleMode` | string | `fit` | How the cell fills the canvas: `fit`, `cover`, `stretch`, `none`, `pattern` |
| `scaling` | string | `nearest` | Interpolation at **akvj draw time**: `nearest` (pixel-art) or `smooth` (bilinear). Mainframe staging/clip preview always uses nearest — it does not follow this field (see `aesthetics.md`). |
| `placement` | `{x, y}` | `{0, 0}` | Offset from canvas centre in pixels. Ignored when `scaleMode` is `stretch`. |

`pattern` tiles the cell at native size across the canvas instead of scaling it; placement shifts
the tile grid origin. Cells larger than the canvas are clipped, as in `none`.

**Whole-pixel rule.** Every draw position and size in `akvj` resolves to an integer pixel via
`snapToPixel()` (`akvj/src/js/utils/snapToPixel.js`). This is engine-wide, not a per-clip setting:
`imageSmoothingEnabled: false` stops scaling interpolation, but a fractional position would still
anti-alias the edge.

### Playback and triggering

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `playback` | string | `loop` | `once`, `loop`, `pingpong`, `random`, `reverse`, `shuffle`, `scrub` |
| `retrigger` | boolean | `true` | Restart from frame 0 when re-triggered |
| `triggerType` | string | `momentary` | `momentary`, `latch`, or `one-shot` |
| `triggerGroup` | string \| number | — | Choke group: triggering a clip stops others in the same group |
| `name` | string | — | Human-readable label |
| `role` | string | — | `bitmask` marks a mixer mask clip |
| `bitDepth` | number | — | Bitmask depth: 1, 2, 4, or 8. Only meaningful with `role: "bitmask"`. |

Legacy `loop: false` still resolves to `playback: "once"`; the pipeline warns and `--fix`
migrates it.

### Timing

| Field | Type | Description |
| --- | --- | --- |
| `frameRatesForFrames` | object | Frame index → FPS |
| `frameDurationsMs` | array | Per-frame milliseconds, one entry per frame. Takes priority over FPS. |
| `sync` | string | `free` (default) or `beat` |
| `syncLength` | string | Required when `sync` is `beat`. A preset or `custom`. |
| `syncBeats` | number | Required when `syncLength` is `custom`. Total clip length in beats. |
| `beatsPerBar` | number | Meter numerator for bar presets. Default `4`. |

Full behaviour: [clip-timing-sync.md](clip-timing-sync.md).

**`frameDurationBeats` is not a field.** It was the old per-frame beat model and the pipeline now
hard-rejects it (`mainframe/scripts/clips/lib/validate/meta.js:17`) with a message pointing at
`sync`/`syncLength`/`syncBeats`.

## `key-map.json`

Nested by **DAW channel (1–16)** → note (0–127) → velocity threshold (0–127). `ClipLoader`
converts to code channels 0–15 when it builds the runtime clip tree.

A velocity leaf is either a bare clip id string or an object with overrides:

```json
{
  "1": {
    "60": {
      "0": "neon-skull",
      "100": { "clipId": "neon-skull", "sync": "beat", "syncLength": "2 bars" }
    }
  }
}
```

Allowed override keys — `triggerType`, `triggerGroup`, `sync`, `syncLength`, `syncBeats`,
`beatsPerBar` (`mainframe/shared/mappingLeaf.js`). `ClipLoader` shallow-merges them over the
clip's own meta at load, so one clip can be free-running in one slot and beat-locked in another
without duplicating it. `placement` is **not** overridable per slot.

## Channel routing

Channel is a routing key independent of clip identity. `key-map.json` decides *which clip plays*;
`settings.js` `channelMapping` decides *what the channel drives*, and that mapping is global,
not per project:

| DAW channels | Routing |
| --- | --- |
| 1–4 | Layer Group A |
| 5 | Mixer (bitmask for A/B crossfade) |
| 6–9 | Layer Group B |
| 10 | Mixed-output effects |
| 11–12 | Layer Group C (overlays) |
| 13 | Global effects |
| 14 | Project selection (note = project index, latched, velocity ignored) |
| 15–16 | Reserved |

## Validation

`npm run clips` validates every clip before generating `clips.json`. The rules live in
`mainframe/scripts/clips/lib/validate/meta.js`; constants are mirrored (never imported across
realms) between `akvj/src/js/visuals/clipMetadata.js` and `mainframe/shared/clipSchema.js`.

Anything the engine tolerates but the pipeline rejects is a defect, not a feature — the two must
agree.

## Not built yet

- **Clip id rename** after create (folder move + key-map rewrite).
- **Per-slot `placement` override** — the mapping override list covers timing and triggering only.
- **Copying clips between projects** — wanted later, so per-project isolation must not block it.
