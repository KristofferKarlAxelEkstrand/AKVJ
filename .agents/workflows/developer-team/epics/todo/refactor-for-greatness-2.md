## How to Start

1. **Pick a task from P0** (P0-1 through P0-5). These are prerequisites.
2. **Open a PR per task.** Each task is independently testable.
3. **Assign to team members** — tasks in the same group (e.g., S1–S4) can run in parallel once P0 passes CI.
4. After P0 + S8 (docs): prioritize **S1** (event hygiene) and **S2** (custom-element naming) — they unblock the rest.
5. Use this file as your checklist. Cross off tasks as PRs land.

## Explicitly Out of Scope

- New features (pianoroll modes, timing/sync UI, scale controls) — those have their own epics
- Changing 60fps rendering or MIDI latency characteristics
- Refactoring beyond the identified debt clusters
- Breaking changes to clip metadata format (hand-editability is sacred)
