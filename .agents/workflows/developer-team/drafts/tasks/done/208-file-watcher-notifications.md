## Problem
The observation dashboard (Task 207) requires manual refresh. We need real-time file watching and notifications to alert the user when events occur in the team protocol.

## Requirements
1. **FileSystemWatcher** — Watch `inbox/`, `slack/*/`, `outbox/`, `tasks/` for file changes
2. **Real-time notifications** — Show VS Code notifications when:
   - New task arrives in inbox
   - Team Lead assigns a task to a developer's slack
   - QA posts a review verdict
   - Report filed in outbox
3. **Auto-refresh dashboard** — Webview updates immediately on file change (not just periodic)
4. **Dashboard generator** — Replace `generate-dashboard.js` with extension-based generation
5. **Debounce** — Coalesce rapid file changes to avoid notification spam

## FileWatcher Implementation
```typescript
class FileWatcher {
  #watcher: vscode.FileSystemWatcher;
  #onFile: (uri: vscode.Uri, type: 'create' | 'change' | 'delete') => void;

  constructor(pattern: string, onFile: typeof this.#onFile) {
    this.#onFile = onFile;
    this.#watcher = vscode.workspace.createFileSystemWatcher(pattern);
    this.#watcher.onDidCreate((uri) => this.#onFile(uri, 'create'));
    this.#watcher.onDidChange((uri) => this.#onFile(uri, 'change'));
    this.#watcher.onDidDelete((uri) => this.#onFile(uri, 'delete'));
  }

  dispose(): void {
    this.#watcher.dispose();
  }
}
```

## Acceptance Criteria
- [x] File changes in watched directories trigger notifications — `FileWatcher` watches `inbox/`, `slack/*/`, `outbox/`, `tasks/` with 4 `FileSystemWatcher` instances
- [x] Dashboard webview updates in real-time on file change — `handleFileEvent` calls `teamPanel.refresh()` on every file event
- [x] Notifications are informative — `formatNotification` generates contextual messages based on folder and filename prefix (e.g., "Task assigned to akvj-developer: [TASK]-205...")
- [x] `dashboard.md` is auto-generated by the extension — `DashboardGenerator` produces same format as `generate-dashboard.js`, tested via Node.js
- [x] Debouncing prevents notification spam — 500ms debounce per file path + event type in `FileWatcher.#handleFile`
- [x] FileWatcher disposes cleanly on deactivate — `FileWatcher` implements `Disposable`, added to `context.subscriptions`
