Compact `## Digest` snapshots imported from the stopped legacy agents. They prevent repeated discoveries and preserve review/test/dependency context without copying live wake transcripts into office-space memory.

- `quality-review-digest.md` — historical review verdicts and gate lessons.
- `test-coverage-digest.md` — coverage and test-reliability findings.
- `dependency-digest.md` — dependency, runtime, and package-health findings.
- `code-quality-digest.md` — naming, documentation, and maintainability findings.
- `product-process-digest.md` — product audits and orchestration observations.

- `akvj-developer-lessons.md` — live-engine constraints and implementation lessons.

- `mainframe-developer-lessons.md` — Mainframe constraints and process lessons.

- `mainframe-developer-digest.md` — bounded implementation history.

- `field-testing-digest.md` — runtime, visual, pipeline, and E2E observations.

Use these for provenance only. New learning goes through `memory-log.js`; lasting rules move into current specs, decisions, or WORKFLOW.
