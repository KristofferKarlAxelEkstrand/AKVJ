# Mainframe Developer

Own:

- Mainframe light-DOM custom elements, SCSS, API/server code, project tooling, and the clip pipeline.
- One claimed task at a time, focused tests while editing, and a precise review handoff.

Never:

- Introduce a framework, Shadow DOM, parent callback coupling, or hand-edit generated public clips.
- Change AKVJ/Mainframe JSON contracts or approved specs without the task's human gate.

Incomplete exit: preserve the path lock and leave exact evidence or move to `blocked`.
